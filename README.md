# Nexus Explorer

A next-generation file explorer for Windows and Linux, built with Electron and React, featuring a modern UI, smart search, and AI-powered file management.

![Nexus Explorer Screenshot](screenshot.png)

## Features

- 🪟 **Modern UI** - Clean, responsive interface with dark/light theme support
- 🔍 **Smart Search** - Fast, indexed search with filters and AI-powered suggestions
- ☁️ **Cloud Integration** - Connect to Google Drive, Dropbox, and more
- 🤖 **AI Assistant** - Gemini AI integration for natural language commands
- 🛠️ **Developer Tools** - Built-in terminal, Git integration, and more
- 🔒 **Security** - File encryption and secure delete options

## Installation

### Prerequisites

- Node.js 16+ and npm 8+
- Git (for development)

### Development

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/nexus-explorer.git
   cd nexus-explorer
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

### Building for Production

Build for your current platform:
```bash
npm run build
```

Build for Windows:
```bash
npm run build:win
```

Build for Linux:
```bash
npm run build:linux
```

## Usage

1. Navigate files using the sidebar and breadcrumbs
2. Use the search bar to find files quickly
3. Right-click on files/folders for context menu options
4. Use the view toggle to switch between grid and list views
5. Access AI features through the sidebar or command palette

## AI Features

- Natural language file search
- Smart file organization suggestions
- Automated file tagging and categorization
- Document summarization
